From retina to two visual streams

One gaze, two views of the world.

The browser demo ports the repository’s fixation-centered retinal coordinate transform to JavaScript. The CNNs themselves are not run in the browser.

01

Move

A fixation defines the center of the retinal coordinate system. Automatic fixations here are an illustrative scanpath; clicking lets you control gaze directly.

02

Sample

A nonlinear radial transform moves sampling locations toward fixation. The two pathways use different density ratios but the same 64 × 64 output grid.

03

Separate

The broader M-like input feeds the WhereCNN for visual attention, while the more foveally concentrated P-like input feeds the WhatCNN for recognition.

What is exact here?

The coordinate warp follows make_xy2ret_grid_r from neural_population.py and starts from the repository defaults: density ratio 2.5 for the dorsal/Where input and 15 for the ventral/What input. The full PyTorch pipeline additionally applies fixation-dependent image foveation before this warp.
